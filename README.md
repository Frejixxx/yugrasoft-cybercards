# «Кибер-карточки Югры» — Интерактивный тренажёр цифровой безопасности (команда «ЮграСофт»)

Игровой обучающий веб-модуль по цифровой безопасности для школьников на платформе **«Цифровой гражданин Югры»** (Хантатон-2026). Полностью закрывает **Базовый**, **Продвинутый** и **Экспертный** треки кейса.

## Файлы и запуск
Модуль написан на чистом **HTML5 / CSS3 / Vanilla JS** (без сборщиков и серверов — открывается двойным кликом в браузере):
- **`index.html`** — основной игровой тренажёр (карточки, симулятор чатов, аналитика и диплом).
- **`demo-portal.html`** — демонстрация встраивания модуля на портал «Цифровой гражданин Югры» через `iframe` + живая телеметрия `postMessage`.
- **`editor.html`** — конструктор новых кибер-карточек для методистов портала (добавление без кода + экспорт JSON).
- **`cards-data.js`**, **`scenarios.js`**, **`scenarios-i18n.js`** — 8 интерактивных карточек и 7 сценариев чатов на 3 языках (**RU / ХАН / EN**).
- **`app.js`**, **`sound.js`**, **`styles.css`** — движок тренажёра, процедурный Web Audio звук, интерактивный фон и генерация PNG-диплома.

## Что реализовано

### 1. Дизайн и игровые механики для детей
- **Светлая палитра портала «Цифровой гражданин Югры»** (без тёмных тем, акцент `#1e5aa8`, дружелюбные шрифты `Rubik` + `Nunito`, цветные обложки под каждую тему).
- **Живой интерактивный фон Югры (Canvas):** светлое дневное небо, плывущие 3D-облака, кубическая тайга и кликабельные летающие 3D-блоки, которые можно «добывать» кликом за `+5 XP`.
- **Перетаскиваемый персонаж «Кибер-Стив»:** перемещается мышкой/пальцем по всей странице, реагирует эмоциями на ответы, даёт подсказки и прокачивает экипировку (очки, алмазный щит и шлем за звёзды).
- **Кастомная «Лупа детектива»:** собственный курсор-лупа при наведении на сценки, кликабельные улики (поддельные ссылки, «бесплатная админка», слабые пароли) и журнал раскрытых улик.
- **Инвентарь кибер-трофеев (хотбар на 8 слотов):** за каждую пройденную карточку выпадает пиксельный предмет защиты.

### 2. Базовый, Продвинутый и Экспертный треки (100% ТЗ)
- **8 интерактивных карточек** и **все 5 типов заданий:** выбор ответа, верно/неверно, сортировка (drag-and-drop), сопоставление пар и порядок действий.
- **Профиль ученика** (ФИО + класс `1–4`, `5–7`, `8–11`) с сохранением в `localStorage`.
- **Адаптивная сложность** (`1 → 2 → 3`) и **6 достижений (ачивок)**.
- **Игровой «Диплом кибергероя» (PNG 1400×940):** генерируется на Canvas с ФИО, звёздами, собранными трофеями, Кибер-Стивом и печатью «Цифровой гражданин Югры».
- **Полная мультиязычность (RU / ХАН / EN):** живой перевод интерфейса, всех 8 карточек и **всех 7 переписок в симуляторе чатов** на русский, хантыйский (казымский диалект) и английский.
- **Аналитика с графиками (Canvas):** точность по типам заданий и динамика прохождений.
- **Симулятор чатов (7 сценариев):** скины/донат, фейк-блогер с кликабельной галочкой Telegram Premium, взломанный друг с голосовым дипфейком и входящими SMS, честный чат с Мамой, дропперство, фейковые Госуслуги и фейковый завуч.
- **Готовая интеграция с порталом:** `iframe` (`?embed=1`) + двусторонний `postMessage` API + конструктор методиста.
