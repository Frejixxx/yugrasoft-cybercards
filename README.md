# «Кибер-карточки Югры» — Интерактивный тренажёр цифровой безопасности (команда «ЮграСофт»)

Игровой обучающий веб-модуль по цифровой безопасности для школьников на платформе **«Цифровой гражданин Югры»** (Хантатон-2026). Полностью закрывает **Базовый**, **Продвинутый** и **Экспертный** треки кейса.

## Структура проекта и запуск
Модуль написан на чистом **HTML5 / CSS3 / Vanilla JS** — **полностью автономный**, без внешних CDN, сборщиков и серверов (все стили, шрифты, иконки и `zxcvbn` собраны локально — открывается двойным кликом в браузере и работает без интернета):

- **`index.html`** — основной игровой тренажёр (карта-тропинка из 18 карточек, симулятор чатов, аналитика и диплом).
- **`demo-portal.html`** — демонстрация встраивания модуля на портал «Цифровой гражданин Югры» через `iframe` + живая телеметрия `postMessage`.
- **`editor.html`** — конструктор новых кибер-карточек для методистов портала (добавление без кода + экспорт JSON).
- **`js/`** — логика и данные тренажёра:
  - `app.js` — движок тренажёра, интерактивный фон Югры, адаптивная сложность, аналитика и генерация PNG-диплома;
  - `cards-data.js` — 18 интерактивных карточек (3 главы-биома) на 3 языках (**RU / ХАН / EN**);
  - `scenarios.js`, `scenarios-i18n.js` — 7 сценариев симулятора чатов на **RU / ХАН / EN**;
  - `sound.js` — процедурный Web Audio звук и плеер офлайн-озвучки;
  - `fio-gender.js` — офлайн-определение напарника по ФИО (включая имена народов Югры).
- **`css/`** — локальные стили (`tailwind.min.css`, `styles.css`, `fonts.css`).
- **`fonts/`** — локальные шрифты `Nunito` и `Tektur` (кириллица + расширенная кириллица для хантыйского).
- **`vendor/`** — локальные копии `lucide.min.js` и `zxcvbn.js`.
- **`audio/`** — 196 студийных MP3-файлов офлайн-озвучки (100% покрытие всех 18 карточек).

## Что реализовано

### 1. Дизайн и игровые механики для детей
- **Светлая палитра портала «Цифровой гражданин Югры»** (без тёмных тем, акцент `#1e5aa8`, шрифты `Tektur` + `Nunito`, цветные обложки под каждую тему).
- **Карта-тропинка по 3 биомам:** «Деревня Югры», «Пещера Фишинга» и «Цитадель Профи» (по 6 карточек в каждой главе).
- **Живой интерактивный фон Югры (Canvas):** светлое дневное небо, плывущие облака, воксельная тайга и кликабельные блоки.
- **Перетаскиваемые персонажи «Кибер-Стёпа» и «Кибер-Алёна» с автовыбором по ФИО:** офлайн-модуль `js/fio-gender.js` сам подбирает напарника по имени или параметру `?fio=...`, а в «Профиле ученика» можно выбрать вручную (там же есть режим учителя/жюри для быстрого открытия всех глав).
- **Студийная офлайн-озвучка (196 MP3):** отдельный мужской голос у Кибер-Стёпы и женский голос у Кибер-Алёны для **всех 18 карточек** (вопросы, объяснения, похвала и поддерживающий разбор каждой ошибки на RU и EN).
- **Кастомная «Лупа детектива»:** курсор-лупа при наведении на сценки, кликабельные улики (поддельные ссылки, «бесплатная админка», слабые пароли) и счётчик найденных улик.
- **Инвентарь кибер-трофеев (хотбар на 6 слотов в каждой главе):** за каждую пройденную карточку выпадает пиксельный предмет защиты.

### 2. Базовый, Продвинутый и Экспертный треки (100% ТЗ)
- **18 интерактивных карточек** и **6 типов заданий:** все 5 из ТЗ (выбор ответа, верно/неверно, сортировка, сопоставление пар, порядок действий) + авторский 6-й тип **«Кибер-верстак» (3×3)**.
- **Профиль ученика** (ФИО + класс `1–4`, `5–7`, `8–11`) с сохранением в `localStorage`.
- **Адаптивная сложность** (`1 → 2 → 3`), подсказки при ошибке, тестер паролей (`zxcvbn` + офлайн-фоллбэк) и **9 достижений (ачивок)**.
- **Игровой «Диплом кибергероя» (PNG 1400×940):** генерируется на Canvas с ФИО, звёздами, собранными трофеями, напарником и печатью «Цифровой гражданин Югры».
- **Мультиязычность (RU / ХАН / EN):** перевод интерфейса, всех 18 карточек и всех 7 переписок в симуляторе чатов на русский, хантыйский (казымский диалект) и английский.
- **Аналитика с графиками (Canvas):** точность по типам заданий, карта навыков и динамика прохождений.
- **Симулятор чатов (7 сценариев):** скины/донат, фейк-блогер с кликабельной галочкой, взломанный друг с голосовым дипфейком и входящими SMS, честный чат с Мамой, дропперство, фейковые Госуслуги и фейковый завуч.
- **Готовая интеграция с порталом:** `iframe` (`?embed=1`) + двусторонний `postMessage` API + конструктор методиста.
